# IB Physics Revision

A small collection of student-facing revision aids for IB Diploma Physics, published as a GitHub Pages site.

**Live site:** https://vcanela.github.io/ib-physics-revision/

## What's here

- **`index.html`** — the landing page students open first; links to everything below.
- **`simulations/`** — 15 single-concept interactive simulations across Themes A to E, with their own themed index (`simulations/index.html`).
- **`guides/`** — two standalone revision guides: the Trap Field Guide and the Concept Cards.

Every file is self-contained HTML: no dependencies, no build step. Open any file directly in a browser, or copy it and share it.

## Deploying updates

This is served by GitHub Pages from the `main` branch, root folder. To publish a change: commit to `main` and push. The site updates within a minute or two.

## Source

These resources are authored in a separate private workbench repo (`IB-revision-ideas`), where the planning documents, question analysis and worksheet sources live. The copies here are the published versions; when a resource is improved in one place, the change is copied to the other so both stay in step.
